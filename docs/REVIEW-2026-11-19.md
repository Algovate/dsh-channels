## 同轮诊断与修复

除独立审查发现外，本轮通过故障注入与并发复现修复六处问题：

| 触发条件 | 修复后的行为 |
|---|---|
| 宿主事件订阅失败 | 注册抛错；回合回落轮询，缺少原生激活守卫时拒绝创建计划 |
| 插件启动途中注册钩子失败 | 移除已装钩子，释放适配器与运行时资源 |
| 两个进程同时首次启动 | 用独占创建的 `state.claim` 串行领取状态锁；中断残留拒绝启动 |
| 入队后 outbox 无法读取 | 返回持久化失败，不报告即时投递成功 |
| 提问到达宿主时限 | finally 撤销原提示，迟到的聊天回答不能再完成该提问 |
| 某聊天上传挂起 | 重试登记按聊天隔离，其他聊天可在后续 drain 中重试 |

正常退出的旧锁持有者仍可自动接管；领取中断遗留文件需先确认相关进程退出，再按运维指南处理。
