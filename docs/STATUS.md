# 验证状态

版本 `0.1.0` 尚未发布。运行 `npm test` 会构建核心和两个适配器，并验证模拟宿主、传输、桌面渲染和状态文件。测试不会连真实机器人。

## 真机证据

以下是早期开发在 DSH `0.2.2-rc.3` 上的验证记录。本轮代码审查未重新使用真实账号验证；不据此承诺其他宿主版本兼容。

| 范围 | 已观察结果 |
|---|---|
| 微信文本 | 真机触发 DSH 回合并收到回复；重启后恢复会话；手机命令已运行 |
| 微信交互 | 编号答复继续同一回合；一次性审批使待执行工具继续 |
| 微信附件 | 入站图片可读，Markdown 正文能进入提示，出站文件返回了平台消息 ID |
| 语音 | 用本地 WAV 单独验证过 ASR 桥；未验证微信语音从平台入站到转写的全流程 |
| 桌面 | 通道徽标、工作区分组、设置落盘、同源校验及宿主存储域均曾验证 |
| Telegram | 使用模拟 Bot API 测试；尚无真实 bot 端到端记录 |

## 已知限制

- 同一个聊天只有一个活动的交互提示。曾观察到桌面返回空答案集后抢先结束提问；聊天不能区分桌面跳过与真正的空答案。
- 宿主没有工作区登记服务或登记失败时，会话可能出现在 **Ungrouped**。
- 每通道只运行一个账号实例。限流计数能持久化，但不协调并发运行的多个实例。
- 持久收件箱恢复尚未开始的普通消息；已开始的回合不会自动重跑。平台响应不明确时，出站重试仍可能重复。重放与去重行为见[运维指南](OPERATIONS.md#状态和重试)。
- 目前只支持一次性审批，视频不抽帧，PDF 正文需要可选解析器。语音和模型依赖的安装方法见[运维指南](OPERATIONS.md#语音转写)。
